---
description: Запуск полного аудита Ozon Кабинет №2
---
Этот ворклоу предназначен для проверки текущего состояния карточек на Ozon (наличие ошибок, статус группировки и SEO).

1. Убедитесь, что в файле `.env` указаны верные `Client-Id` (311191) и `Api-Key`.
2. Запустите консольный аудит:
// turbo
```powershell
python scripts_tool/ozon2_total_verify.py
```
3. Проверьте вывод на наличие ошибок атрибутов или Model ID.
