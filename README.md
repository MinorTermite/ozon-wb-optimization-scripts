# GRAVMIX Workspace: Optimization & Automation

Добро пожаловать в рабочее пространство Antigravity. Здесь собраны инструменты для автоматизации работы с маркетплейсами Ozon, Wildberries и Яндекс Маркет.

## 🏗 Структура проекта

- `/scripts_tool/` — **Основные рабочие инструменты**. Здесь находятся актуальные скрипты для SEO, группировки товаров и исправления ошибок.
- `/data_dump/` — **Данные и отчеты**. JSON дампы из API, CSV отчеты по рекламе и юнит-экономике.
- `/audit_logs/` — **Логи и диагностика**. Результаты проверок и технические логи.
- `/archives/` — **Архив**. Устаревшие версии скриптов и временные наработки.
- `/src/` — **Ядро**. Будущие модули и общие библиотеки.
- `/config/` — (В планах) Централизованные настройки.

## ⚙️ Настройка среды

1. **Environment**: Основные ключи хранятся в корне в файле `.env`.
    > [!IMPORTANT]
    > Никогда не коммитьте `.env` в публичные репозитории. Он добавлен в `.gitignore`.
2. **Запуск**: Любой скрипт из `scripts_tool` можно запустить напрямую:

    ```bash
    python scripts_tool/ozon2_total_verify.py
    ```

## 🛠 Описание инструментов в `scripts_tool/`

### 🌀 Ozon (Кабинет №2)

- **`ozon2_total_verify.py`** — Мастер-скрипт для полного аудита. Проверяет названия, характеристики, наличие фото и ошибки в 130+ карточках.
- **`ozon2_granular_split_v2.py`** — Умное разделение товаров. Распределяет "кучу" (heap) по тематическим группам (Знаки Зодиака, Семья, Авто и др.) на основе ключевых слов в названиях.
- **`ozon2_precise_cleanout.py`** — Инструмент финальной зачистки. Дорабатывает товары, которые не попали в основные группы, используя расширенный список SEO-ключей.
- **`ozon2_seo_apply.py`** — Массовое обновление SEO-заголовков и поисковых запросов через API Ozon.

### 🟣 Wildberries

- **`wb_full_audit.py`** — Глубокий технический аудит всех карточек (266+ штук). Выявляет пропуски в характеристиках и короткие описания.
- **`wb_seo_fix.py`** — Мощный SEO-движок. Автоматически расширяет описания до оптимальной длины и вписывает ключевые слова.
- **`wb_restore_prices.py`** — Скрипт экстренного восстановления цен. Используется для отката цен к эталонным значениям в случае ошибок.
- **`wb_unit_economics.py`** — Расчет реальной прибыли с учетом логистики, комиссии и налога.
