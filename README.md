### Настройка окружения

1. Скопировать `.env.example` → `.env`
2. Заполнить API-ключи:

```env
WB_API_KEY=ваш_ключ_wildberries
OZON_CLIENT_ID=ваш_client_id
OZON_API_KEY=ваш_ключ_ozon
YM_OAUTH_TOKEN=ваш_токен_yandex
YM_CAMPAIGN_ID=ваш_id_кампании
```

3. Установить зависимости:
```bash
pip install requests python-dotenv
```

## 🧠 Ключевые стратегии

### 1. Re-creation Strategy (обнуление рейтинга)

**Проблема**: 39 карточек с плохим рейтингом (≤3) из-за жалоб на качество (краска стирается, застёжка слабая, неверная надпись).

**Решение** — `wb_perfect_cloner.py`:
```python
# Что делает клонер:
# 1. Читает список nm_id из analytics/wb_recreate_nmids.json
# 2. Копирует: subjectID, title, description, characteristics, dimensions, photos
# 3. Устанавливает новый vendorCode = старый + "_CLONED"
# 4. Передаёт skus=[] → WB генерирует новые штрихкоды
# 5. Новая карточка получает статус "Новинка" и нулевой рейтинг
```

```bash
python scripts_tool/wb_perfect_cloner.py
```

**Технические нюансы**:
- `skus` должен быть `[]` — не передавать старые штрихкоды
- Вес: если `weightBrutto < 1` (кг), умножить на 1000 → граммы
- Габариты не могут быть `0` (минимум `1`)
- Rate limit 429 → `time.sleep(60)`

### 2. SEO-стратегия 2026

**Ключевые слова для заголовков**:
- гравировка, 2026, именной, подарок, браслет, сталь 316L
- персональный, нержавеющая сталь, гипоаллергенный

**Правила заголовков**:
- Лимит WB: 60 символов → используем 50 для гарантированного прохождения модерации
- Включать главный ключ в начало заголовка


## 🔧 Технические требования

### WB API v2

```
Endpoint создания карточек: POST https://content-api.wildberries.ru/content/v2/cards/upload
Endpoint обновления:        POST https://content-api.wildberries.ru/content/v2/cards/update
Заголовок:                  Authorization: Bearer {WB_API_KEY}

Ограничения:
  - Rate limit:     429 → sleep(60)
  - Пакет загрузки: до 100 карточек за запрос
  - Вес:           не может быть 0 (ID характеристики: 14177450)
  - Габариты:      width/height/length >= 1
```

### Ошибки валидации и их исправления

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Заголовок не прошёл | >60 символов | Сократить до 50 |
| Чёрновик / не активен | Нет обязательных характеристик | Заполнить Габариты + Вес |
| Штрихкод занят | Старые skus переданы при клонировании | Передавать `skus: []` |
| 429 | Превышен rate limit | `time.sleep(60)` |

### Характеристики WB

| ID | Название | Обязательно |
|----|---------|-------------|
| 14177450 | Вес товара с упаковкой (г) | ✅ |
| — | Материал | Желательно |
| — | Пол | Желательно |
| — | Цвет | Желательно |
