# Example Scenarios From Your Catalog

Эта заметка нужна, чтобы не думать каждый раз, чем заполнять шаблоны.

## 1. Обычный ремешковый браслет для мамы

Подходит для:
- `Gemini/01_Product_Cover_Strap.md`
- `ChatGPT/01_Product_Cover_Strap.md`
- `Gemini/05_Gift_Lifestyle.md`
- `ChatGPT/05_Gift_Lifestyle.md`

Подстановка:
- `{{RECIPIENT}}` = `мама`
- `{{OCCASION}}` = `день рождения / 8 марта / просто личный подарок`
- `{{ENGRAVING_TEXT}}` = `Спасибо, мама, что ты есть у меня`
- `{{PRODUCT_TYPE}}` = `ремешковый браслет с гравировкой`

## 2. Зодиакальный ремешковый браслет

Подходит для:
- `Gemini/02_Zodiac_Strap.md`
- `ChatGPT/02_Zodiac_Strap.md`
- `Gemini/04_Engraving_Closeup.md`
- `ChatGPT/04_Engraving_Closeup.md`

Подстановка:
- `{{ZODIAC_SIGN}}` = `Рыбы` или конкретный нужный знак
- `{{RECIPIENT}}` = `муж / сестра / подруга / универсально`
- `{{ENGRAVING_TEXT}}` = `Рыбы`
- `{{MEANING}}` = `личный талисман, знак зодиака, подарок со смыслом`
- `{{PRODUCT_TYPE}}` = `зодиакальный ремешковый браслет`

## 3. Кафф для подруги

Подходит для:
- `Gemini/03_Cuff_Bracelet.md`
- `ChatGPT/03_Cuff_Bracelet.md`
- `Gemini/04_Engraving_Closeup.md`
- `ChatGPT/04_Engraving_Closeup.md`

Подстановка:
- `{{RECIPIENT}}` = `подруга`
- `{{OCCASION}}` = `день рождения / памятный подарок`
- `{{ENGRAVING_TEXT}}` = `{{ВАША_РЕАЛЬНАЯ_ГРАВИРОВКА_НА_КАФФЕ}}`
- `{{PRODUCT_TYPE}}` = `кафф-браслет`
- `{{MEANING}}` = `личный подарок с гравировкой`

Важно:
- не подставлять знак зодиака;
- не использовать промпты для ремешкового браслета.

## 4. Браслет с молитвой / смысловой гравировкой

Подходит для:
- `Gemini/01_Product_Cover_Strap.md`
- `ChatGPT/01_Product_Cover_Strap.md`
- `Gemini/04_Engraving_Closeup.md`
- `ChatGPT/04_Engraving_Closeup.md`
- `Gemini/05_Gift_Lifestyle.md`
- `ChatGPT/05_Gift_Lifestyle.md`

Подстановка:
- `{{RECIPIENT}}` = `муж / друг`
- `{{OCCASION}}` = `личный подарок, знак поддержки`
- `{{ENGRAVING_TEXT}}` = `Отче наш / Псалом 90 / Ангелу хранителю`
- `{{MEANING}}` = `поддержка, вера, защита, памятный подарок`
- `{{PRODUCT_TYPE}}` = `ремешковый браслет с молитвой`

## 5. Короткий чек перед каждой генерацией

- Я загрузил именно эталонные фото нужного SKU?
- Я выбрал правильный шаблон: ремешковый / зодиак / кафф?
- Я не смешал кафф и ремешковый браслет?
- Я не добавил зодиак туда, где его нет?
- Я дал модели конкретную гравировку и получателя?
