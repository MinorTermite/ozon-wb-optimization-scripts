# Documentation Basis

Ниже — не теория, а те правила, которые реально полезны под вашу задачу.

## OpenAI / ChatGPT

Что важно из официальной документации:
- OpenAI рекомендует писать промпты ясно и конкретно, а ограничения и формат задавать прямо в инструкции.
- Для изображений OpenAI рекомендует использовать не только текстовую генерацию, но и режимы генерации/редактирования изображений, если важно сохранить объект и дальше итеративно его дорабатывать.
- В image generation guide отдельно сказано, что для image flows доступны настройка качества, размера, формата и многошаговое редактирование через conversational flow.

Практический вывод под ваши браслеты:
- Для ChatGPT нельзя полагаться на короткий "красивый" запрос.
- Лучше давать полный блок: цель, неизменяемые свойства товара, допустимые изменения, запреты, сцена, требования к читаемости гравировки, проверка результата.
- Для реального товара лучший режим — `reference photos + edit`, а не свободная text-to-image фантазия.

Источники:
- [OpenAI Image Generation Guide](https://platform.openai.com/docs/guides/images/image-generation)
- [OpenAI Prompting Guide](https://platform.openai.com/docs/guides/prompting)

## Gemini

Что важно из официальной документации:
- Google рекомендует давать ясные и конкретные инструкции.
- Gemini особенно хорошо реагирует на структурированные промпты с тегами или Markdown-блоками.
- В official prompt guide прямо рекомендованы few-shot примеры, явные ограничения и четкое разделение контекста и задачи.
- В image generation docs есть отдельный режим `image editing (text-and-image-to-image)`, то есть использование эталонных фото как базы — это корректный и рекомендованный сценарий.

Практический вывод под ваши браслеты:
- Для Gemini лучше писать промпты в структурированном виде.
- В начале нужно положить роль и инварианты товара.
- После этого отдельно дать `reference truth`, `allowed changes`, `task`, `output goals`.
- Для ремешковых браслетов и каффов нельзя использовать один и тот же промпт: Gemini надо сразу жестко зафиксировать тип товара.

Источники:
- [Gemini Prompt Design Strategies](https://ai.google.dev/guide/prompt_best_practices)
- [Gemini Image Generation](https://ai.google.dev/gemini-api/docs/image-generation)

## Что я взял в промпты как обязательные правила

- Сначала фиксировать реальный физический товар.
- Потом задавать только допустимые изменения сцены и подачи.
- Для зодиакальных браслетов знак должен быть явно поддержан и текстом, и композицией.
- Для не-зодиакальных браслетов нельзя подмешивать астрологию.
- Для обычных ремешковых браслетов нельзя использовать слово `кафф`.
- Для каффов нельзя использовать черный ремешок и круглый медальон ремешкового браслета.

## Что ломает результат чаще всего

- Короткий промпт без эталонных фото.
- Попытка сразу получить "идеальную обложку", "подарочную сцену" и "инфографику" в одном запросе.
- Слабый блок запретов.
- Нечеткое указание, что именно является неизменяемым в самом браслете.
