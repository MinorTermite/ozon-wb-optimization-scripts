### Текущее техническое состояние сценария `-5%`

- Скрипт умеет:
  - подключаться к текущей Edge CDP-сессии,
  - брать уже открытую вкладку цен,
  - скачивать актуальный шаблон,
  - пересчитывать цены,
  - загружать файл в модалку.
- Скрипт не добит только в одном месте:
  - финальное подтверждение `Обновить` в модальном окне не запускает обработку.
- Симптом:
  - файл загружается,
  - имя файла видно в модалке,
  - но маркер обработки на `120` товаров не появляется.
- Последняя верификация после попытки дала:
  - `95/120` совпадений по ожидаемым ценам,
  - `25` несовпадений.
- Это значит:
  - новый `-5%` слой не применился,
  - фактические цены остались на уровне предыдущего `-10%`.

### Следующий ход по цене

- Не открывать новую вкладку `prices` через `goto`: были `ERR_CONNECTION_RESET`.
- Работать только с уже открытой вкладкой цен из текущей CDP-сессии.
- Открывать модалку только DOM-click-ом.
- Дальше добивать именно modal-submit:
  - ждать, пока кнопка `Обновить` внутри модалки станет активной,
  - кликать только по кнопке внутри диалога, а не глобально по странице,
  - после этого повторять выгрузку и сверку до `120/120`.
