# Gemini And Video Limits

## Что уже удалось

Через браузер был собран рабочий automation-поток для `Gemini Pro`.

Ключевые скрипты:
- `scripts_tool/gemini_generate_video_browser_20260412.js`
- `scripts_tool/gemini_video_status_poll_20260412.js`
- `scripts_tool/gemini_download_video_20260412.js`
- `scripts_tool/gemini_attach_reference_current_20260412.js`

## Что принципиально не сработало

Для браслетов с точной гравировкой `Gemini` как финальный генератор непригоден.

Причины:
- модель уводит объект в другой тип украшения;
- может сделать не тот браслет;
- не держит побуквенную точность гравировки;
- при edit/reference сценарии текущий flow утыкался в явную просьбу загрузить image reference;
- attach image через текущий DOM-flow был нестабилен.

## Зафиксированный технический вывод

`Gemini` использовать только для:
- черновых lifestyle-идей;
- moodboard;
- фоновых подходов;
- тестовых роликов без критичного текста на изделии.

`Gemini` не использовать как финальный источник для:
- карточки товара с обязательной точной гравировкой;
- Wibes-видео, если ролик должен показывать именно реальный SKU;
- любых продуктовых кадров, где пользователь потом увидит несовпадение товара.

## Рабочая замена

Когда нужен точный коммерческий контент:
- брать реальный браслет;
- брать реальные stills;
- собирать локально через Python/ffmpeg;
- публиковать уже exact-product clip.

## Дополнительный факт

Пользователь прямо зафиксировал проблему:
- `генерация вообще не похожа на мой браслет`

Это не вкусовой комментарий, а запрет на дальнейшую публикацию подобных генераций без product-truth контроля.
