# Obsidian Prompts For Bracelet Images

Эта папка — рабочая библиотека промптов под ваши реальные браслеты для ручной или полуавтоматической генерации изображений в браузере.

Структура:
- `00_Documentation_Basis.md` — краткая выжимка из актуальной документации OpenAI и Gemini по тому, как писать промпты.
- `01_Bracelet_Reference_Truth.md` — зафиксированная визуальная правда по вашим браслетам.
- `06_Marketplace_Context_Reset_Memory_20260414.md` — широкая reset-memory заметка по всему стеку маркетплейсов и смежных каналов.
- `07_Ozon_Context_Reset_Memory_20260414.md` — первая точка входа после сброса контекста для всех задач по Ozon.
- `99_AGENT_RESET_MEMORY_INDEX_20260414.md` — быстрый индекс по product/content handoff после сброса контекста.
- `AGENT_RESET_MEMORY_20260414/` — сжатый handoff-пакет по Wibes, visual pipeline, product truth и reset-протоколу.
- `Gemini/` — промпты под Gemini web / Gemini image workflows.
- `ChatGPT/` — промпты под ChatGPT web image workflows.

Как использовать:
1. Выберите нужный сценарий.
2. Загрузите в чат 2-4 эталонных фото товара.
3. Подставьте значения в плейсхолдеры вида `{{...}}`.
4. Вставьте промпт целиком.
5. Если модель искажает форму браслета, не правьте товар словами "похоже" или "примерно". Усиливайте блок `immutable product truth`.

Базовый порядок эталонных фото:
1. Фронтальный ракурс.
2. Ракурс 3/4.
3. Крупный план гравировки.
4. Фото упаковки или сцены подарка, если нужно.

Жесткое правило:
- Ремешковые браслеты не превращать в кафф.
- Каффы не превращать в ремешковые браслеты.
- Не придумывать новую геометрию, фурнитуру, застежку, форму пластины, толщину или тип изделия.

Задача этих промптов:
- повысить CTR карточки;
- сделать визуал правдивым;
- не терять SEO-смыслы из title и карточки;
- не допускать визуальной подмены товара.
