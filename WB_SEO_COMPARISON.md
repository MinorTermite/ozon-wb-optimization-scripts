## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Rate Limits Wildberries API
```
Лимит: 10 запросов в минуту
Интервал: 6 секунд между запросами (минимум)
Burst: 5 запросов одновременно

Наш подход: 7 секунд между пакетами (безопасный запас)
Максимум карточек в запросе: 3000
Наш размер пакета: 100 (оптимально для обработки ошибок)
```

### Обработка ошибок
```python
# Старый подход
if r.status_code == 200:
    # Считали успехом, но не проверяли resp_json['error']
    
# Новый подход  
if r.status_code == 200:
    resp_json = r.json()
    if resp_json.get('error'):
        # Обрабатываем ошибки валидации даже при 200 OK
        print(f"VALIDATION ERROR: {resp_json.get('errorText')}")
```

## 🎯 КЛЮЧЕВЫЕ ИЗМЕНЕНИЯ В КОДЕ

1. **Пакетирование**
   ```python
   # БЫЛО
   for i, c in enumerate(cards_data):
       card_body = {...}
       r = requests.post(URL, json=card_body)  # ❌
   
   # СТАЛО
   for batch_idx in range(0, len(cards), BATCH_SIZE):
       batch = cards[batch_idx:batch_idx+BATCH_SIZE]
       batch_payload = [create_card(c) for c in batch]
       r = requests.post(URL, json=batch_payload)  # ✓
   ```

2. **Валидация ответа**
   ```python
   # БЫЛО
   if r.status_code == 200:
       print("SUCCESS")  # Некорректно!
   
   # СТАЛО
   if r.status_code == 200:
       resp = r.json()
       if not resp.get('error'):
           print("SUCCESS")  # Корректно!
   ```

3. **Rate limit compliance**
